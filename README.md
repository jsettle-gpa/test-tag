test-tag
========

Tag-gateway Ignition project for the Ignition-template validation pass. Seeded from the Elev8 Tag project content.

This repo holds only the project content — Perspective views, scripts, named queries, vision, webdev. Gateway configuration, docker-compose, and tooling live in the customer environment repo that mounts this repo as a submodule under `projects/test-tag/`.

Branch convention: `dev` is the default working branch.
